## Status legend

- ✅ **Finalized** — validated in sync, ready for / in dev handoff
- 🔄 **Iterating** — direction approved, revisions in progress
- 🧪 **Exploration** — comparison / option study, not a candidate build
- 📁 **Superseded** — kept for iteration trail; see newer version

## How this index is maintained

A prototype gets a row here **in the same commit** that adds its HTML file. Superseded versions keep their rows (status changed to 📁) so the iteration trail stays visible. One line per prototype — richer context lives in the respective Figma module files.
